----------------------------------------------------------------------
ARCHITECTURE — CJK-COMPLETE CORE + OPTIONAL FULL FONT PACK (v1.1.0+)
----------------------------------------------------------------------

Starting with v1.1.0, this skill uses a two-tier distribution with a
deliberately CJK-complete core. Design rationale:

Pre-v1.1.0 core (v1.0.x) bundled 24 fonts, all of which were Google
Fonts distribution subsets that do NOT contain CJK ideographs (한자).
The skill's own philosophy names (餘白·丹靑·縫補·古調·餘湍) rendered
as tofu (□) unless the user separately installed the Full Font Pack
via scripts/install_full_fonts.{sh,ps1}.

Claude Desktop and claude.ai web users cannot run the Full Pack
installer — these environments only accept ZIP uploads. This meant
the skill's core Korean aesthetic (which fundamentally requires 한자)
was permanently inaccessible to those users.

v1.1.0 resolves this by rebuilding the core around 5 CJK-complete
fonts that fit within Claude Desktop's 30 MB uncompressed skill limit.

  * CJK-COMPLETE CORE (this package, ~28.5 MB uncompressed):
    - NotoSansKR-VF.ttf          — variable sans-serif, 8566 CJK
    - NanumMyeongjo-OldHangul.ttf   — serif + 옛한글, 5005 CJK
    - NanumBrushScript-Regular.ttf  — brush calligraphy, 4888 CJK
    - NanumPenScript-Regular.ttf    — pen script, 4888 CJK
    - JejuGothic-Regular.ttf        — regional display, 4888 CJK
    All five support 餘白, 丹靑, 縫補, 古調, 餘湍 natively, without
    any additional installation step.

  * FULL FONT PACK (separate, ~110 MB) — optional download via
    scripts/install_full_fonts.sh (or .ps1 on Windows).
    Adds 124 more typefaces including Pretendard (all weights),
    NanumSquare/Round/Neo full weights, NanumGothic full family,
    NanumBarunGothic, NanumMyeongjo subset variants, Eco patterns,
    GowunBatang/GowunDodum, JejuMyeongjo/JejuHallasan, Hahmlet,
    D2Coding, BlackHanSans, DoHyeon, Jua, Sunflower-Bold, WorkSans,
    Lora, Italiana, BigShoulders, InstrumentSerif, JetBrainsMono,
    and more. Full Pack installation is Claude Code only — Claude
    Desktop and claude.ai web do not support running scripts.

----------------------------------------------------------------------
MODIFICATIONS FROM THE ORIGINAL
----------------------------------------------------------------------

Cumulative changes introduced in canvas-design-kr through v1.1.0:

1. Extended SKILL.md with Korean-aesthetic content:
   - 5 new design philosophies: 餘白 (Yeobaek), 丹靑 (Dancheong),
     縫補 (Jogakbo), 古調 (Gojo), 餘湍 (Yeotan)
   - Korean color systems: 오방색, 오간색, 자연염색 palette
   - Hangul typography rules: font-script pairing, Hangul-Latin-CJK
     mixing, vertical writing (세로쓰기), 옛한글 support
   - RULE 0: Environment detection + font discovery
   - RULE 1 (v1.1.0): "Core already supports CJK"
   - pick_cjk_font() helper with priority ordering

2. Core font bundle (v1.1.0): 5 CJK-complete typefaces listed above.

3. Full Font Pack (separate, v1.1.0): 124 additional typefaces.
   Previously-core fonts (Pretendard, NanumSquare family, NanumGothic
   subsets, BlackHanSans, DoHyeon, Sunflower, WorkSans, Lora, etc.)
   were moved to the Full Pack in v1.1.0.

4. Distribution infrastructure:
   - .github/workflows/release.yml — automatic ZIP build on tag push
   - scripts/build_core_from_fullpack.{sh,ps1} — maintainer tool to
     extract 5 core fonts from a locally-installed Full Pack and
     build the v1.1.0 core ZIP
   - scripts/install_full_fonts.{sh,ps1} — Full Pack installer
     (Claude Code environments only)
   - scripts/discover_fonts.py — font discovery diagnostic

5. Re-licensed under Apache License 2.0 (same as original) with
   updated copyright attribution and modification notice.
